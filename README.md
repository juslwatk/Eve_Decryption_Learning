To run this program, you will need pytorch installed. I have provided the requirements.txt file that contains a suitable environment 
To download it use:

python -m venv venv
venv\Scripts\activate    # Windows
# or
source venv/bin/activate # Mac/Linux

pip install -r requirements.txt
